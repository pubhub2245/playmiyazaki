# Play Miyazaki（playmiyazaki.com）要件

## これは何か
宮崎で「遊ぶ」ための専門一覧サイト。サーフィン・キャンプ／車中泊・食・ゴルフの4ジャンルについて、宮崎県内のお店・施設・スポットを「そのジャンルなら日本一くわしい一覧」として載せる。日本語が正、英語版を同時に出す。

じゅんさんの稼働を最小にした、オンライン完結の副収入ビジネス（目標：月3〜5万円の営業利益）。

## 誰のためか
- 宮崎に遊びに来る人（県外・海外）。今は Google で「宮崎 サーフィン スクール」などと検索して、個人ブログの「10選」記事や予約サイトを何個も開いて比べている
- 掲載される側の事業者（将来の有料枠の顧客）

## 1つだけやるなら
「宮崎の○○（ジャンル）を探すなら、ここを見れば全部ある」状態を作る。網羅性が価値。

## 成功の測り方
**Google 検索からの月間クリック数（Search Console の数字）。** これが伸びない限り、紹介料も掲載枠も動かない。
- 6か月後の目安：月1,000クリック
- 12か月後の目安：月5,000クリック → ここで有料掲載枠を開く

## ジャンルと着手順（成功確度の高い順）
1. **サーフィン**（サーフショップ・スクール・レンタル・サーフポイント・サーファー向け宿）— 競合は予約サイトと個人ブログだけで「全網羅の一覧」が無い。海外客が多く英語版が効く
2. **キャンプ・車中泊**（キャンプ場・RVパーク・車中泊OKスポット・温泉）
3. **食**（地鶏炭火焼・焼酎蔵見学・農園体験・マンゴー等の直売所）
4. **ゴルフ**（ゴルフ場・練習場・ゴルフ宿）— 県公式サイトと楽天GORA・じゃらんゴルフが強いので最後

## 収益（段階的に）
- 第1段階（公開〜半年）：収益なし。掲載情報の網羅と検索流入の積み上げだけ
- 第2段階（検索流入が付いてから）：紹介料（楽天トラベル・じゃらん・アソビュー・Amazon）
- 第3段階（月5,000クリック目安）：事業者向け「おすすめ掲載枠」（月3,000〜5,000円、カード決済で自動）
- 第4段階：広告

## やらないこと
- ユーザー登録・ログイン（今はやらない。有料枠を出すときに事業者用だけ作る）
- 口コミ・レビュー投稿（永久にやらない。管理コストと法的リスクの塊）
- 予約機能（永久にやらない。予約サイトへ送って紹介料を取る側に立つ）
- 事業者への営業・問い合わせ・電話（永久にやらない。向こうから来る形だけ）
- 有料広告の出稿（今はやらない）
- アプリ化（永久にやらない）
- 情報の創作（永久にやらない。出典URLのない項目は載せない。営業時間や料金が分からなければ「公式サイトで確認」と表示する）

## 私（Claude）が代わりに決めたこと
- **データベースを使わず、JSON ファイルで管理する**：月数百件の一覧に DB は要らない。Supabase を持つと監視と課金が付いてくる。ゼロ円・ゼロ管理で動くことを優先。有料枠を出す段階で Supabase を足す
- **英語版は自動翻訳をビルド時に作り、JSON に保存する**：閲覧のたびに翻訳APIを呼ぶと課金される。翻訳は Claude Code が作業時に生成して JSON に書き込む
- **URL は `/ja/surf/...` と `/en/surf/...`**：検索エンジンに日本語版と英語版を別ページとして認識させるため
- **写真は使わない（第1段階）**：他人の写真は権利問題、AI生成は「実在の店の写真」として誤解を招く。地図（Google マップへのリンク）と文字情報で勝負する
- **月1回の更新作業はスケジュール実行で回す**：「新しい掲載先を探して追加する」を Claude が自動でやり、じゅんさんは追加候補の承認だけ
- **名前は Play Miyazaki**：ドメインと同じ。日本語表記は「プレイ宮崎」ではなく英字のまま
