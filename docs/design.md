# Play Miyazaki デザイン設計書

見た目に関する判断は、この文書だけを根拠にする。ここに無い値・部品は使わない。数値は「出発点」であり、実測で問題が出れば実測を優先して直す（直したらこの文書も更新する）。

## 海外先行事例の共通点（2026年9月14日に実際に閲覧して抽出）
見たサイト：OpenAlternative（月約100万円・一人運営）、SaaSHub（月1万ドル超）、There's An AI For That、Nomads.com、Hipcamp、The Dyrt。ジャンルは違っても作りは驚くほど同じだった。以下を **全部** 入れる。

A. **ヘッダーに「掲載する／Submit」の入口がある。** 事業者側から来てもらう導線。OpenAlternative の "Submit"、Hipcamp の "List your property"、The Dyrt の "List Your Property"。有料枠を出す前から入口だけ置く
B. **トップ以外はパンくずが必ずある。** SaaSHub / Hipcamp / The Dyrt 全部。検索エンジンにも階層を伝える
C. **一覧ページの上に検索ボックスが1つ。** どのサイトも見出しのすぐ下。凝った検索ではなく「名前で絞る」だけで十分
D. **絞り込みはチップ（タグ）で、件数つき。** TAAFT のタブ（Tools 52,996 / Devices 588 …）、Hipcamp のアイコン付きチップ、OpenAlternative の Filters。件数が付いていると「網羅している」ことが伝わる
E. **1件の表示は「識別マーク＋名前＋1行説明＋事実の行 2〜3 本」。** OpenAlternative は Stars / Last commit / License を点線リーダーで左ラベル・右値に並べる。Hipcamp は Pets / Toilets / Campfires。**この「事実の行」がディレクトリらしさの正体**。写真が無くても識別マーク（ロゴの代わりに頭文字のモノグラム）と事実の行があれば成立する
F. **数字を隠さない。** "47,630 factors"、"10,000+ Reviews"、"Trusted by 15k+ people"。件数・確認日など、信頼の材料になる数字は全部見せる
G. **詳細ページは「左に名前と説明とボタン、右に事実の表」。** OpenAlternative の詳細は左に名前・タグライン・"Visit" ボタン、右に Stars / Last commit / License / Repository の表、その下に関連。ボタンはページに1つだけ
H. **「おすすめ枠／Sponsored」は一覧の中で見た目が違う。** OpenAlternative は薄い着色＋ラベル、SaaSHub は "sponsored" ラベル。派手にせず、ラベルと左端の線で区別する

## 方向（1つだけ）
**「宮崎の海辺の潮見表」。**
上の A〜H の型に、海の家の壁に貼ってある潮見表の見た目を載せる。事実が罫線で整然と並んでいて、余計な飾りが無い。紙の色は砂浜の白、罫線は流木色、見出しは海の色。写真は使わない。

言い換え：
- 派手にしない。整えることで「ちゃんとしている」と感じさせる
- 色はほぼ2色（砂と濃紺）。海の青は「ここぞ」だけ
- 数字・日付・種別ラベルは等幅フォント。これが「記録」「一覧表」らしさを作る

## シグネチャー（大胆さの予算を全部使う場所）
ジャンル一覧ページ上部の**「潮見表の帯」**。全幅の海色（--sea）の帯にジャンル名を白で大きく置き、帯の下辺を波形にする。**ジャンル一覧ページにだけ**出す。取り外したらページが別物になる、というのがシグネチャーの条件。

## フォント（next/font/google で自己ホスト）
| 役割 | フォント | ウェイト | 用途 |
|---|---|---|---|
| display | Zen Kaku Gothic New | 700 | 見出し・スポット名・ジャンル名・モノグラム |
| body | Zen Kaku Gothic New | 400 | 本文・説明・表の値 |
| mono | IBM Plex Mono | 400, 500 | 種別ラベル・エリア・件数・日付・パンくず・出典URL・事実の行 |

英語ページも同じ3役で同じフォント。
サイズ（出発点）：本文 15px／行間 1.7。スポット名 18px。ページ見出し 28px。トップ見出し 32px。詳細の名前 32px。帯のジャンル名 40px（スマホ 28px）。mono ラベル 12px、字間 0.04em。確認日 11px。

## 地（環境）
body 背景 --canvas。固定レイヤー（fixed, z-index 0, pointer-events none, aria-hidden）で上端 --sky → 320px で --canvas に溶けるグラデーション。動かさない。

## 波のマーク（ロゴ・favicon）
24×24 の viewBox に、左から右へ 2 つの山を持つ波線 1 本（stroke 2px、丸端、fill なし）。ヘッダーでは --text-primary、favicon では --sea 地に --on-sea の線。文字ロゴは "Play Miyazaki"（display 700）。

## 4ジャンルの線画ピクトグラム（トップの板）
32×32 viewBox、stroke 1.5px、丸端、fill なし、--text-primary。surf：波線2本／camp：三角テントと入口の縦線／food：炎の輪郭1本／golf：旗竿と小さな旗。記号であって挿絵ではない。

## 行の構造（E の実装。一覧・同じエリア・最近確認 で共通）
```
[モノグラム 40px]  名前（display 700 18px）                     確認 2026-09-14
                    1行説明（body 14px、--text-secondary）
                    種別 ·········· サーフスクール      エリア ·········· 日向市
```
- モノグラム：名前の頭文字（日本語1文字／英字2文字）を display 700 16px、--panel 地の 6px 角丸、--text-primary 文字
- 事実の行：mono 12px。ラベルは --text-secondary、値は --text-primary。間の点線リーダーは --line の dotted border-bottom（flex で ラベル・リーダー・値 の3要素）
- 行の区切りは --line 1px。ホバーで背景 --panel
- 小型版（同じエリア／最近確認）：モノグラム 32px、事実の行は1本（エリアのみ）
- おすすめ枠（featured: true のとき。今は無い）：左端に --accent 3px の縦線、右上に mono 11px「掲載枠」ラベル。それ以外は同じ

## チップ（D）
高さ 32px（coarse pointer では 44px）、角丸 999px、枠 --line-strong 1px、文字 mono 13px。右に件数（mono、--text-secondary）。選択中は地 --text-primary・文字 --on-dark・枠なし。ホバーで地 --panel。

## 検索ボックス（C）
高さ 44px、枠 --line-strong 1px、角丸 8px、左に虫眼鏡の線画（16px、aria-hidden）。フォーカスで枠が --accent。クライアント側で名前・エリア・種別の文字を部分一致で絞る。結果0件なら「見つかりませんでした。別の言葉で探してください。」を body で表示。

## レイアウトの骨格（隣り合う区画で同じ形を繰り返さない）
- トップ：見出し＋補足 → 検索 → 4枚の板（2列）→ 最近確認したスポット（小型行）
- ジャンル一覧：帯 → パンくず → 検索 → チップ → 小見出し付き罫線リスト
- 種別・エリア一覧：パンくず → 見出し → チップ（もう一方の軸）→ 罫線リスト
- 詳細：パンくず → 2カラム（左：名前・チップ・説明・ボタン／右：事実の表）→ 同じエリアのスポット
- 掲載申請ページ（/submit）：パンくず → 見出し「掲載を申請する」→ 本文3行 → 「準備中」
- フッター：濃紺の地に 注意書き・サイト名・掲載申請リンク

## 動き
イージングは 2 つだけ：--ease-out: cubic-bezier(0.22, 1, 0.36, 1)、--ease-inout: cubic-bezier(0.65, 0, 0.35, 1)。
- 一覧の行：表示時に 0→1 のフェードと 8px の持ち上がり、60ms ずつ遅延。終わったら遅延を 0 に戻す
- ホバー：背景色 200ms --ease-out
- 生きている要素はページに1つ：帯の件数の数え上げ（600ms）
- prefers-reduced-motion では全部止めて最終状態で出す

## コピーの声
地元の人が友達に教える口調。短く、事実だけ、盛らない。禁止語：最高、絶景、おすすめ、厳選、充実、魅力、〜だけじゃない、emダッシュ。
- トップ見出し：ja「宮崎で遊ぶ場所を、全部。」en「Every place to play in Miyazaki.」
- トップ補足：ja「サーフィン・キャンプ・食・ゴルフ。出典つきで {n} か所。」en「Surf, camp, food and golf. {n} places, every one with a source.」
- 注意書き：ja「掲載情報は出典URLに基づいています。営業時間・料金は変わることがあります。」
- 掲載申請：ja「掲載は無料です。公式サイトなど出典になるページのURLを添えてお知らせください。受付窓口は準備中です。」

## やらないこと（デザイン面）
- 写真・イラスト・AI画像
- カード型のグリッド（罫線リストで統一。トップの4枚の板だけ例外）
- ボタンは詳細ページの「公式サイトを見る」1つだけ。他はリンクとチップ
- 影（box-shadow）とグラデーションボタン
- 3色目のアクセント
- 地図の埋め込み（Google マップへのリンクのみ。APIキーは課金の芽）
