## 1. 紹介リンク（第2段階）

### 1-1. どの listing に出すか
- `golf` … 楽天GORA・じゃらんゴルフ（もしも経由）に同じコースがあるもの
- `camp` … なっぷ／楽天トラベルキャンプ（同上）
- `surf` の `stay`、`golf` の `stay-onsite` を持つもの … 楽天トラベル・じゃらん
- `food` … 原則なし（飲食は紹介料の口が弱い。ぐるなび等は「予約」の匂いが出るので置かない）

### 1-2. データの持ち方（**ここは新項目なので、CLAUDE.md の原則5により じゅんの「はい」が要る**）
listing JSON に任意の項目 `booking` を1つ足す：
```json
"booking": [
  { "site": "rakuten-gora", "url": "https://gora.golf.rakuten.co.jp/guide/gcxxxx/", "verified_at": "2026-09-17" }
]
```
- `url` は素の予約サイトURL（紹介IDは入れない）。紹介IDはビルド時に環境変数から付ける（`NEXT_PUBLIC_AF_RAKUTEN_ID`、`NEXT_PUBLIC_AF_MOSHIMO_*`）。IDが未設定なら**素のリンクのまま出す**（壊れない）
- `site` の値は固定の列挙：`rakuten-travel` / `jalan` / `rakuten-gora` / `jalan-golf` / `nap`
- `lib/types.ts` の zod に `booking` を optional で追加。`sources` と同じく URL 検証
- 予約サイトのページが「同じ施設」であることの確認は、施設名＋住所の一致。確認できないものは付けない（出典の原則と同じ）

### 1-3. 見た目（design.md 準拠）
- 場所：詳細ページ左カラム、`pm-btn`（公式サイト）と Google マップリンクの行の**次の行**
- 形：`pm-mono text-[13px] text-accent` の文字リンク。ボタンにしない（ボタンは1ページ1つの原則）
- ラベル：リンクの左に `pm-mono text-[11px] text-text-secondary` で「紹介リンク」／「affiliate」
- 文言：ja「楽天GORAで見る ↗」「じゃらんで見る ↗」 en「See on Rakuten GORA ↗」
- `rel="sponsored noopener noreferrer"` `target="_blank"`
- 一覧の行には**出さない**（行は事実だけ。行を触ると網羅一覧の見た目が崩れる）

### 1-4. 紹介リンクの作り方（参考。実装時に各ASPの管理画面の形式で上書き）
- 楽天アフィリエイト：管理画面の「リンク作成」で対象URLを入れて出るURL（`hb.afl.rakuten.co.jp/hgc/<ID>/?pc=<encoded url>` 形式）。ビルド時に `encodeURIComponent(url)` を埋めるだけ
- もしも：`af.moshimo.com/af/c/click?a_id=..&p_id=..&pc_id=..&pl_id=..&url=<encoded url>`。じゃらんは「URL自由指定」対応の案件を選ぶ
- どちらも計測用の `<img>` ピクセルを要求することがある。要求されたら 1×1 の `img` を `aria-hidden` でリンク直後に置く（写真なし原則の例外にはあたらない）

## 2. 広告枠（第4段階・AdSense）

### 2-1. 位置
1. **一覧ページの末尾**：`FilteredCategoryGroups`（または `FilterableList`）の直後、`main` の中の最後の要素。ここが「読み終えた人」だけが見る位置で、一覧の網羅感を邪魔しない
2. **詳細ページの事実の表の下**：`aside` 内、`bg-panel/60` の表の下に 16px 空けて置く。右カラム幅 18rem に収まる 300×250 を想定
- トップページには置かない（トップは「宮崎で遊ぶ場所を、全部。」だけを見せる）
- `/private` 配下には置かない（別ブランドの売り場）
- 情報ページ（about/privacy 等）には置かない

### 2-2. 見た目
- 枠の上に `pm-mono text-[11px] text-text-secondary` で「広告」／「Ad」
- 枠は `min-height` を固定（一覧末尾 280px、詳細 250px）。**レイアウトのずれ（CLS）を出さない**。広告が入らないときは空のまま（枠線は引かない）
- 色・影・枠線は足さない。アクセント色を使わない

### 2-3. 実装の形
- `app/_components/AdSlot.tsx`（`"use client"`）：`slot` 属性を受け、`NEXT_PUBLIC_ADSENSE_CLIENT` が未設定なら **何も描画しない**（今の本番は一切変わらない）
- `app/(site)/layout.tsx` に AdSense の `<script async>` を `next/script`（`strategy="afterInteractive"`）で1回だけ。同じく環境変数が無ければ入れない
- 環境変数はじゅんが Vercel に1回入れるだけ（本人の一度きりの入力）
- 自動広告（Auto ads）は**オフ**にする。位置が制御できず、帯や板の間に入るため

### 2-4. 審査に要るもの（このブランチで用意済み）
- 運営者情報 `/ja/about` `/en/about`
- プライバシーポリシー `/ja/privacy`（広告 Cookie・オプトアウトの記載あり）
- お問い合わせ `/ja/contact`（`NEXT_PUBLIC_CONTACT_EMAIL` を入れると mailto が出る。未設定は「準備中」）
- 広告と紹介リンクについて `/ja/disclosure`
- 残り：`ads.txt`（AdSense 承認後に `public/ads.txt` を1行置く。内容は AdSense 画面が出す）
