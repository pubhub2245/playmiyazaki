【前提】
CLAUDE.md と docs/auto/2026-09-17_IndexNow.md を先に読むこと。
IndexNow ＝ 更新したURLを検索エンジン側に「こちらから」知らせる無料の仕組み（Bing・DuckDuckGo などが対応。Google は非対応）。
コードはすでに入っている。この作業は **最初の1回だけ、全URLを送る** もの。アカウント登録も支払いも発生しない。

【やること】STEP 21：IndexNow の初回送信（1回きり）
1. 本番に鍵のファイルが出ているかを確かめる。
   curl -s -o /dev/null -w "%{http_code}" https://playmiyazaki.com/6d342d605825c8df006e797e5deed1de.txt
   200 以外なら **何も送らず終了**し、RESULT に「鍵のファイルが本番に出ていない（HTTP ◯◯）」と書く。
   （本番反映がまだ済んでいないだけなので、失敗ではない。次回の queue で再実行すればよい）
2. 200 だったら、全URLを1回だけ送る：
   npm ci → npm run indexnow -- --all
3. 送った件数と返事のコードを RESULT に書く。**コードの変更もコミットも不要**（送るだけの作業）。

【禁止】鍵の文字列の変更、listing JSON の変更、--all を2回以上送ること（以後はビルドのたびに変わった分だけ自動で送られる）
RESULT 行：鍵のファイルの HTTP コード／送ったURL数／IndexNow の返事のコード
